# Enferium Telegram Bot + 3x-ui

Бот для продажи VPN-подписок через Telegram и 3x-ui.

## Что изменено

- Каждая новая покупка создаёт отдельную подписку и отдельного клиента в 3x-ui. Срок существующей подписки не продлевается.
- Внизу Telegram-чата есть постоянные кнопки «Тарифы», «Мои подписки» и «Админ-панель».
- Во время отправки чека появляется кнопка «❌ Отмена оплаты» — `/start` для отмены больше не нужен.
- `PAYMENT_DETAILS` поддерживает `\\n` из `.env` и показывает реквизиты с переносами строк.
- Перед показом «Мои подписки» бот сверяет клиентов с 3x-ui. Если клиента удалили или отключили в панели, подписка помечается неактивной в боте.
- Фактический `expiryTime` клиента из 3x-ui синхронизируется с БД.
- Ссылка подписки строится из `SUBSCRIPTION_URL_TEMPLATE`.

## URL подписки

Для текущей конфигурации:

```env
SUBSCRIPTION_URL_TEMPLATE=https://ru.enferium.ru:2026/minecraft/{sub_id}
```

## Важно

`.env` и реальные секреты в архив не включены. Не публикуйте `BOT_TOKEN`, API token, пароль 3x-ui или Reality private key.
